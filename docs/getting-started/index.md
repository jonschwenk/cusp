# Get CUSP

You can download and analyze CUSP without installing the Python package. Start
with the versioned release, then use the pages in this section to interpret and
cite it responsibly.

## Recommended Path

1. [Download the data](release-products.md) and keep the versioned CSV,
   bibliography, and `RELEASE_INFO.md` together.
2. Read [Caveats and limits](caveats.md) before deciding which observations fit
   your analysis.
3. Follow [Using the data](using-the-data.md) for a short guide to loading,
   interpreting, and filtering the table.
4. Read [Attribution and BibTeX](../user/data-use-and-attribution.md) before
   publishing or distributing results.

## Reference Pages

- [Data schema](../user/data-schema.md) defines every release column.
- [Quality flag definitions](../user/quality-flags.md) explains the compact
  caveat codes stored in `quality_flags`.
- [What CUSP is](what-is-cusp.md) describes the scope of the synthesis.

The optional command-line workflows are grouped under [CUSP tools](../user/index.md).
